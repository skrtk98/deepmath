# タグ付け規則

この文書は、DeepMath の概念索引に用いるタグの統制語彙と運用を定める。
タグは記事の題名を列挙するためではなく、異なる分野の記事を横断して探索するために用いる。

## 二層のタグ体系

各実質的な概念ページには、分野階層タグを一つと、横断概念タグを一つから三つ付与する。
通常は合計二つから四つのタグとし、発見可能性を増やさない追加は行わない。

### 分野階層タグ

分野階層タグは、その記事を読む際の第一の数学的文脈を示す。
主分野は一つだけ選ぶ。
二つ目の分野階層タグは、二つの分野が記事の定義または主要定理に等しく必要な場合に限る。

階層は日本語のスラッシュ区切りで記す。
深さは原則として二階層、必要な場合でも三階層までとする。

- `基礎論/集合論`、`基礎論/数理論理学`
- `圏論`、`圏論/モノイダル圏論`、`圏論/豊穣圏論`、`圏論/高次圏論`
- `代数学/群論`、`代数学/環論`、`代数学/加群論`、`代数学/体論`、`代数学/ホモロジー代数`
- `幾何学/位相幾何学`、`幾何学/微分幾何学`、`幾何学/複素幾何学`、`幾何学/代数幾何学`
- `解析学/実解析`、`解析学/関数解析`、`解析学/測度論`、`解析学/微分方程式論`
- `数論`、`組合せ論`、`確率論`、`統計学`、`数理情報学`、`数理物理学`

新しい分野を導入するときは、既存の上位分野で意味が失われるかを確認する。
意味が失われる場合だけ、新しい階層タグを追加する。

### 横断概念タグ

横断概念タグは、分野をまたいで再利用される構造、構成、性質、または中心的な理論装置を示す。
`準同型`、`部分構造`、`商構成`、`生成`、`双対性`、`完全性`、`可換性`、`普遍性`、`函手`、`テンソル積` はこの層に属する。

記事名と同じタグは自動的には付与しない。
ただし、その概念が他の記事の定義または主張を組織する再利用可能な語である場合には付与する。
`モノイダル圏`、`豊穣圏`、`随伴`、`米田埋め込み` はこの条件を満たす。
一回限りの固有名、記事の文書種別、単なる難易度や学習順序を概念タグに用いない。

## 表記と統制

タグは既存の表記を優先し、同義語、略称、送り仮名の違いを新しいタグとして増やさない。
例えば `Hom` と `Hom 集合` は対象の意味が異なるため使い分けるが、同じ意味の別表記を併存させない。
英語名または人名を含むタグは、日本語名が定着していない場合か、他の記事との探索上必要な場合に限る。

タグが一ページだけに現れる場合は、横断的な探索に寄与するかを確認する。
寄与しない場合は、そのタグを削除するか、より一般的な既存タグへ置き換える。

## リンクとの役割分担

タグは横断探索の入口を与える。
Markdown リンクは、定義の前提、双対概念、具体例、一般化、証明上の依存を示す。
タグで結び付く二記事が、読解上も直接参照すべき関係にある場合には、本文の初出または関連項目にリンクを置く。

## 追加時の確認

1. 主分野を一つ選ぶ。
2. 横断概念を一つから三つ選び、既存表記を検索する。
3. 題名タグを加える場合には、他の記事の探索語として再利用されることを確認する。
4. 主要な前提概念、双対概念、一般化先を Markdown リンクで確認する。
5. `uv run mkdocs build` により front matter とリンクを検証する。
