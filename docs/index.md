# DeepMath

**DeepMath** は、数学およびその周辺分野 (理論計算機科学・数理物理・論理学など) を
厳密かつ有機的に記述することを目的とした、オープンな数学 wiki です。

学部生から研究者まで、数学の構造を深く理解したい人のために書かれています。

## 設計思想

DeepMath は「正確に、しかし孤立させずに」を合言葉に書かれています。

定義は厳密に書きますが、それだけでは数学の面白さは伝わりません。
なぜその概念が生まれたのか、他のどんな概念とつながっているのか——
そうした文脈ごと記述することを大切にしています。

また、教科書で止まらないことも意識しています。
各トピックが現代数学のどこに位置づけられるかを示し、
さらに先を学びたい人への道しるべになることを目指しています。
