# 分野拡充の草稿

このディレクトリには、公開前の数学記事の草稿を置く。
草稿は通常のサイトビルドから除外し、開発サーバーでのみ確認する。

各草稿は、公開記事へ分割する概念、既存記事との接続、および記述時に確認する事項を定める。
公開時には、記事ごとに理論的な内容、記法、日本語表現、内部リンクおよびタグを確認する。

## 作成順序

1. [基礎論と線形代数](./foundations_and_linear_algebra.md)を整備し、後続分野で用いる共通の前提を明示する。
2. [代数幾何学](./algebraic_geometry.md)を整備し、既存の可換環論と圏論の記事を接続する。
3. [数理論理学と集合論](./logic_and_set_theory.md)を整備し、形式化と圏論的論理への入口を置く。
4. [実解析と確率論](./real_analysis_and_probability.md)を整備し、測度論から確率論へ至る依存関係を記述する。
5. [組合せ論と離散数学](./combinatorics_and_discrete_mathematics.md)を整備し、離散構造の基礎概念を追加する。
6. [数論](./number_theory.md)を整備し、既存の代数的数論の記事を初等的な前提と接続する。
