# 草稿：数論

## 目的

整数論の基礎概念から代数的数論への入口を整備し、既存の[Dedekind 整域](../wiki/dedekind_domain.md)を初等的な前提と接続する。
初等数論と代数的数論では、対象となる環および体を明示して区別する。

## 公開候補の記事

- **整除**：整除関係、最大公約数、最小公倍数および Euclid の互除法を記述する。
- **素数**：素元、既約元および素イデアルとの関係を記述する。
- **合同**：合同関係、剰余環、逆元および中国剰余定理を記述する。
- **算術関数**：加法的関数、乗法的関数、Möbius 関数および Dirichlet 畳み込みを定める。
- **有限体**：有限体の存在と同型を除く一意性、有限体上の多項式を記述する。
- **ガロア理論**：体拡大、自己同型群、固定体およびガロア対応を記述する。
- **代数体**：数体、整数環、判別式および素イデアル分解を定める。
- **イデアル類群**：分数イデアル、主イデアル、類群および一意分解との関係を記述する。

## 既存記事との接続

[ユークリッド整域](../wiki/euclidean_domain.md)、[主イデアル整域](../wiki/principal_ideal_domain.md)および[一意分解整域](../wiki/unique_factorization_domain.md)が整除論の代数的な前提となる。
[体](../wiki/field.md)、[体拡大](../wiki/field_extension.md)および[代数的拡大](../wiki/algebraic_extension.md)がガロア理論と数体論の前提となる。

## 記述上の確認事項

素元と既約元の一致には、整域であることと適切な分解性の仮定が必要である。
合同は整数に限らず一般の環で定義できるが、初等数論の記事では対象環を明示する。
ガロア対応では、有限ガロア拡大などの仮定を省略しない。
