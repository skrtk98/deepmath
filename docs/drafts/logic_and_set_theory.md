# 草稿：数理論理学と集合論

## 目的

数学的対象を記述する形式言語、証明体系および集合論的基礎を導入し、圏論的論理と数理情報学への接続を準備する。
基礎体系の選択に依存する主張は、その体系を明示して記述する。

## 公開候補の記事

- **一階述語論理**：言語、項、論理式、自由変数、束縛変数および解釈を定める。
- **形式体系**：公理、推論規則、定理および導出を定める。
- **モデル理論の基礎**：構造、充足関係、部分構造および準同型を定める。
- **健全性定理**：導出可能性が意味論的帰結を導くことを記述する。
- **完全性定理**：一階述語論理における意味論的帰結と導出可能性の一致を記述する。
- **ZFC 集合論**：公理の役割、選択公理および通常の数学との関係を記述する。
- **型理論**：型、項、依存型および証明とプログラムの対応を導入する。
- **トポスの内部論理**：部分対象分類子と高階論理の関係を記述する。

## 既存記事との接続

[圏](../wiki/category.md)、[関手](../wiki/functor.md)および[随伴函手](../wiki/adjoint_functor.md)は、圏論的論理を記述する際の前提となる。
[直積圏](../wiki/product_category.md)と[指数対象](../wiki/closed_monoidal_category.md)は、型理論との比較を行う際に参照する。

## 記述上の確認事項

対象言語とメタ言語、構文論と意味論、証明可能性と真理を区別する。
完全性、不完全性および決定可能性の定理は、対象とする論理体系を明示する。
内部論理は、任意の圏ではなく適切な構造をもつ圏で定式化されることを明記する。
