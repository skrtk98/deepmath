# 草稿：代数幾何学

## 目的

可換環論、圏論および幾何学を接続するため、アファインスキームから層とスキームへ至る基礎概念を段階的に記述する。
初期段階では、古典的な代数集合とスキーム論の定式化を区別する。

## 公開候補の記事

- **素イデアル**：素イデアル、極大イデアル、根基および商環との関係を定める。
- **環のスペクトル**：$`\operatorname{Spec} A`$ の点、Zariski 位相および基本開集合を定める。
- **局所化**：既存の[局所化](../wiki/localization_of_ring.md)を、素イデアルにおける局所化と局所環へ接続する。
- **層**：前層、制限写像および局所的な貼り合わせ条件を定める。
- **アファインスキーム**：局所環付き空間としての $`\operatorname{Spec} A`$ を定める。
- **スキーム**：アファインスキームによる局所被覆と貼り合わせを定める。
- **スキームの射**：連続写像と構造層の射からなる射を定める。
- **スキームのファイバー積**：圏論的[引き戻し](../wiki/pullback.md)との関係を記述する。

## 既存記事との接続

[環](../wiki/ring.md)、[イデアル](../wiki/ideal_in_rings.md)、[局所環](../wiki/local_ring.md)および[体拡大](../wiki/field_extension.md)が代数的な前提となる。
[前層](../wiki/presheaf.md)、[極限](../wiki/limit.md)および[普遍性](../wiki/universal_property.md)が圏論的な前提となる。

## 記述上の確認事項

零環を含めるかどうか、スペクトルの点を素イデアルと同一視する文脈、および既約閉集合との対応の仮定を明示する。
層条件では、局所切断の一致と貼り合わせの一意性を分けて記述する。
スキームのファイバー積の構成は、アファインの場合と一般の場合を混同しない。
