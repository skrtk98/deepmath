# 草稿：実解析と確率論

## 目的

既存の[測度空間](../wiki/measure_space.md)と[可測関数](../wiki/measurable_function.md)を出発点として、積分論、収束定理および確率論の基礎概念を接続する。
実解析では、位相的な極限と測度論的な収束を区別する。

## 公開候補の記事

- **可測空間**：$`\sigma`$-代数、可測写像および可測空間の射を定める。
- **測度**：可算加法性、完備化および測度空間を定める。
- **Lebesgue 積分**：単関数、可積分関数および積分を定める。
- **収束定理**：単調収束定理、Fatou の補題および優収束定理の仮定と結論を記述する。
- **確率空間**：全測度が $`1`$ である測度空間として定める。
- **確率変数**：可測写像として定め、分布および期待値との関係を記述する。
- **条件付き期待値**：部分 $`\sigma`$-代数に関する可積分確率変数として定める。
- **確率分布**：押し出し測度として定め、独立性および確率収束への接続を記述する。

## 既存記事との接続

[距離空間](../wiki/metric_space.md)、[位相空間](../wiki/topological_space.md)および[ネット](../wiki/net.md)は、収束の位相的な側面を記述する際に参照する。
[Banach 空間](../wiki/banach_space.md)と[Hilbert 空間](../wiki/hilbert_space.md)は、$`L^p`$ 空間および直交射影を記述する際に参照する。

## 記述上の確認事項

測度の定義域、可測性の基準となる $`\sigma`$-代数、および積分可能性の仮定を明示する。
ほとんど至る所の同値と点ごとの等号を区別する。
条件付き期待値は一意ではなく、ほとんど至る所の一致を除いて一意であることを記述する。
