# 草稿：基礎論と線形代数

## 目的

基礎論と線形代数の概念を整備し、既存の代数学、解析学、幾何学および圏論の記事で用いる共通の言語を明示する。
特に、集合、関係、商、順序および有限次元線形代数を、後続の記事へのリンクを伴って記述する。

## 公開候補の記事

- **集合**：外延性、部分集合、直積、冪集合および写像との関係を定める。
- **関係**：二項関係、合成、逆関係および関係のグラフを定める。
- **同値関係**：反射律、対称律、推移律および同値類を定める。
- **商集合**：同値関係から得られる商集合と、商写像の普遍的性質を記述する。
- **半順序集合**：半順序、全順序、単調写像、上界および下界を定める。
- **行列**：行列の演算、線形写像の表示、基底変換および合成との関係を記述する。
- **行列式**：交代多重線形性による特徴付け、可逆性および基底変換を記述する。
- **固有値と固有ベクトル**：固有空間、特性多項式および対角化可能性を定める。

## 既存記事との接続

[ベクトル空間](../wiki/vector_space.md)、[線形写像](../wiki/linear_map.md)および[双線形写像](../wiki/bilinear_map.md)を、線形代数の記事群の出発点とする。
[群表現](../wiki/group_representation.md)では、行列表示、固有空間および不変部分空間へのリンクが必要となる。
[商群](../wiki/quotient_group.md)および圏論における[余等化子](../wiki/cokernel.md)は、商構成を横断的に参照する。

## 記述上の確認事項

集合とクラス、関係と写像、商集合と代表元の選択を混同しない。
行列は基底を選んだ線形写像の表示であり、線形写像そのものではないことを明記する。
固有値の議論では、基礎体と有限次元性の仮定を明示する。
