# 自由加群

## 定義

可換環 $`R`$ と集合 $`X`$ を考える。

> [!definition] 自由加群
> $`R`$-加群 $`F`$ と写像 $`i\colon X\to F`$ の組が **$`X`$ 上の自由 $`R`$-加群** (*free $`R`$-module on $`X`$*) であるとは、任意の $`R`$-加群 $`M`$ と写像 $`f\colon X\to M`$ に対して、$`f=\widetilde f\circ i`$ を満たす一意な $`R`$-線形写像 $`\widetilde f\colon F\to M`$ が存在することである。

このとき $`i(X)`$ を基底とみなし、$`F`$ を $`X`$ を基底とする自由加群という。

## 構成と例

集合 $`X`$ に対して、$`X`$ から $`R`$ への有限台関数全体 $`R^{(X)}`$ は $`X`$ 上の自由 $`R`$-加群である。

特に、$`X`$ が $`n`$ 個の元からなるとき、$`R^{(X)}`$ は $`R^n`$ と同型である。

任意の $`R`$-加群は、ある自由 $`R`$-加群の商加群として表せる。
