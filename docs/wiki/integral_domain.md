# 整域

## 定義

> [!definition] 整域
> **整域** (*integral domain*) とは、$`0_R\ne1_R`$ を満たす可換環 $`R`$ であって、任意の $`a,b\in R`$ に対し、$`ab=0_R`$ ならば $`a=0_R`$ または $`b=0_R`$ が成り立つものである。

すなわち、整域は自明環ではなく、零因子を持たない可換環である。

## 例

整数環 $`\mathbb{Z}`$ は整域である。

また、体 $`k`$ と正整数 $`n`$ に対して、多項式環 $`k[x_1,\dots,x_n]`$ は整域である。

一方、合成数 $`n>1`$ に対する $`\mathbb{Z}/n\mathbb{Z}`$ は零因子を持つため、整域ではない。

## 関連する概念

体は整域である。

整域は、分数体の構成および一意因数分解に関する議論の基礎となる。
