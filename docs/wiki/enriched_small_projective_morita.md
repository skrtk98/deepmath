# 豊穣小射影と Morita 同値

豊穣 Morita 理論は、豊穣圏を対象の表示ではなく豊穣前層の理論によって比較する。
この比較では、表現可能前層から有限的に見える情報を抽出する小射影前層と、そこから作る Cauchy 完成が中心となる。

以下では、$`\mathcal{V}`$ を対称モノイダル閉圏とし、豊穣前層圏および必要な小余極限が存在すると仮定する。
$`A,B`$ は小さい $`\mathcal{V}`$-圏とする。

## 小射影前層

豊穣前層 $`P\in[A^{\mathrm{op}},\mathcal{V}]`$ が **小射影** であるとは、Hom 函手

```math
[A^{\mathrm{op}},\mathcal{V}](P,-)
\colon[A^{\mathrm{op}},\mathcal{V}]
\longrightarrow\mathcal{V}
```

が小さい重み付き余極限を保存することである。

表現可能前層 $`y(a)=A(-,a)`$ は小射影である。
小射影前層は、表現可能前層そのものだけでなく、その絶対重み付き余極限から得られる前層も含む。
したがって、小射影前層全体は表現可能前層を Cauchy 完備化する際に加わる対象を記述する。

## Morita 同値

> [!definition] 豊穣 Morita 同値
> $`A`$ と $`B`$ が **豊穣 Morita 同値** であるとは、豊穣前層圏の豊穣同値
>
> ```math
> [A^{\mathrm{op}},\mathcal{V}]
> \simeq
> [B^{\mathrm{op}},\mathcal{V}]
> ```
>
> が成り立つことである。

この定義は、$`A`$ と $`B`$ が同じ種類の豊穣前層、したがって同じ豊穣的な表現論を与えることを表す。
圏同値は Morita 同値を導くが、Morita 同値は一般に圏同値より弱い。

## Cauchy 完成による判定

> [!theorem] Cauchy 完成による Morita 同値の判定
> $`A`$ と $`B`$ が豊穣 Morita 同値であることと、その豊穣 Cauchy 完成が豊穣同値
>
> ```math
> Q(A)\simeq Q(B)
> ```
>
> であることは同値である。

前層圏の同値は小射影前層を小射影前層へ送るため、$`Q(A)`$ と $`Q(B)`$ の同値を誘導する。
逆に、Cauchy 完成の同値は、それぞれの小さい重み付き余極限による閉包である前層圏の同値を誘導する。

$`\mathcal{V}=\mathsf{Set}`$ の場合、この判定は Karoubi 完成が同値であることによる通常の Morita 同値の判定となる。
特に、冪等射の分裂を除けば同じ対象を表す二つの圏は、同じ前層圏を与える。

## 表現可能前層との関係

豊穣米田埋め込み $`A\to[A^{\mathrm{op}},\mathcal{V}]`$ は、$`A`$ を表現可能前層の充満部分圏として実現する。
Morita 理論では、表現可能前層の選び方自体ではなく、その Cauchy 完成である小射影前層の充満部分圏が不変となる。

豊穣 Cauchy 完成の定義と普遍性は [豊穣 Cauchy 完成](./enriched_cauchy_completion.md) を、表現可能前層の復元公式は [豊穣米田の補題](./enriched_yoneda_lemma.md) を参照されたい。
