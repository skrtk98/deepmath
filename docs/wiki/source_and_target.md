# 始点と終点

射 $`f\colon X\to Y`$ を書くとき、$`X`$ と $`Y`$ は合成可能性を決める。

この二つを明示すると、射の向きと合成の型が定まる。

## 定義

> [!definition] 始点と終点
> 圏 $`\mathcal{C}`$ の射 $`f\colon X\to Y`$ に対して、$`X`$ を $`f`$ の **始点** (*source*)、$`Y`$ を $`f`$ の **終点** (*target*) という。

始点を domain、終点を codomain と呼ぶこともある。

部分写像を扱う文脈では domain と codomain が別の技術的意味を持つことがあるため、本ノートでは射については始点と終点を用いる。

## 小圏における記述

小圏 $`\mathcal{C}`$ の対象集合と射集合をそれぞれ $`\mathcal{C}_0`$、$`\mathcal{C}_1`$ と書く。

このとき、始点写像と終点写像は
```math
s,t\colon\mathcal{C}_1\longrightarrow\mathcal{C}_0
```
で与えられ、射 $`f`$ に対して $`s(f)` と $`t(f)`$ はそれぞれその始点と終点である。

合成 $`g\circ f`$ は $`t(f)=s(g)`$ のときにのみ定義される。

## 内部圏への一般化

内部圏では、対象と射を表す対象 $`C_0,C_1`$ および射 $`s,t\colon C_1\to C_0`$ を基礎圏の内部に取る。

この一般化では、始点と終点は集合上の関数ではなく、基礎圏における射として扱われる。
