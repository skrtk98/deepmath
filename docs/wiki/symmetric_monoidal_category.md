# 対称モノイダル圏

組紐を二度適用すると恒等になる場合、組紐付きモノイダル圏を**対称モノイダル圏**という。

## 定義と例

> [!definition] 対称モノイダル圏
> 組紐付きモノイダル圏が対称であるとは、任意の対象 $`X,Y`$ に対して $`\beta_{Y,X}\circ\beta_{X,Y}=1_{X\otimes Y}`$ が成り立つことである。

$`\mathsf{Set}`$ の直積、$`\mathsf{Ab}`$ と $`\mathsf{Vect}_k`$ のテンソル積は対称モノイダル圏を与える。
任意のカルテシアン圏は、積の座標交換により自然に対称モノイダル圏となる。
