# 豊穣函手圏

豊穣函手圏は、二つの豊穣圏の間の豊穣函手を対象とし、それらの間の比較も基底圏の対象として持つ豊穣圏である。
前層圏と豊穣米田の補題は、この構成を用いて定式化される。

以下で $`\mathcal{V}`$ を対称モノイダル閉圏、$`A`$ を小さい $`\mathcal{V}`$-圏、$`B`$ を $`\mathcal{V}`$-圏とする。
必要なエンドが $`\mathcal{V}`$ に存在すると仮定する。

## 定義

> [!definition] 豊穣函手圏
> **豊穣函手圏** $`[A,B]`$ は、$`A`$ から $`B`$ への $`\mathcal{V}`$-函手を対象とし、二つの豊穣函手 $`F,G\colon A\to B`$ の Hom 対象を
>
> ```math
> [A,B](F,G)
> =int_{a\in A}B(Fa,Ga)
> ```
>
> とする $`\mathcal{V}`$-圏である。

エンドの楔条件は、各 $`a`$ における比較が $`A`$ の Hom 対象の作用と両立することを要請する。
したがって、この Hom 対象は成分ごとの写像の単なる積ではなく、豊穣自然性を満たす比較だけを集めたものである。

単位射と合成射は、各成分における $`B`$ の単位射と合成射からエンドの普遍性により定まる。

## 下部圏と豊穣自然変換

$`[A,B]`$ の下部圏 $`[A,B]_0`$ の射は

```math
\mathcal{V}(I,[A,B](F,G))
```

である。
エンドの普遍性により、これは $`I\to B(Fa,Ga)`$ の族であって豊穣自然性条件を満たすもの、すなわち豊穣自然変換 $`F\Rightarrow G`$ に一致する。

$`\mathcal{V}=\mathsf{Set}`$ の場合、Hom 対象は自然変換の集合となる。
このとき上のエンド公式は、通常の函手圏の射が自然変換であることを表す。

## 内部 Hom との関係

$`\mathcal{V}`$ が十分な完備性をもち、$`A`$ が小さいとき、豊穣函手圏は $`\mathcal{V}\text{-}\mathsf{Cat}`$ における内部 Hom の役割を果たす。
すなわち、$`\mathcal{V}`$-圏 $`C`$ に自然な対応

```math
\mathcal{V}\text{-}\mathsf{Cat}(C\otimes A,B)
\cong
\mathcal{V}\text{-}\mathsf{Cat}(C,[A,B])
```

が得られる。
この対応は、二変数豊穣函手を一変数の豊穣函手へ移す豊穣版のカリー化である。

$`B=\mathcal{V}`$ と置くと、$`[A^{\mathrm{op}},\mathcal{V}]`$ は豊穣前層圏となる。
豊穣自然変換の成分による定義は [豊穣自然変換](./enriched_natural_transformation.md) を、エンドの定義は [エンドとコエンド](./end_and_coend.md) を参照されたい。
