# ネット

ネットは、有向集合で添字付けた点族である。
一般の位相空間で点列より柔軟に収束とコンパクト性を記述できる。

## 有向集合とネット

> [!definition] 有向集合
> 前順序集合 $`(\Lambda,\leq)`$ が **有向集合** であるとは、任意の $`a,b\in\Lambda`$ に対して $`a\leq c`$ かつ $`b\leq c`$ を満たす $`c\in\Lambda`$ が存在することである。

> [!definition] ネット
> 有向集合 $`\Lambda`$ から集合 $`X`$ への写像を **ネット** といい、通常 $`(x_\lambda)_{\lambda\in\Lambda}`$ と書く。

部分集合 $`A\subseteq X`$ に対し、ネットが $`A`$ に **最終的に含まれる** とは、ある $`\lambda_0`$ 以降のすべての $`x_\lambda`$ が $`A`$ に属することである。
ネットが $`A`$ に **しばしば含まれる** とは、任意の $`\lambda`$ の後に $`A`$ に属する項が存在することである。

## 部分ネットと普遍ネット

ネット $`(y_\mu)_{\mu\in M}`$ が $`(x_\lambda)_{\lambda\in\Lambda}`$ の **部分ネット** であるとは、順序を保つ強共終写像 $`\phi\colon M\to\Lambda`$ が存在して

```math
y_\mu=x_{\phi(\mu)}
```

が成り立つことである。
強共終性とは、任意の $`\lambda\in\Lambda`$ に対して、ある $`\mu_0\in M`$ が存在し、$`\mu\geq\mu_0`$ ならば $`\phi(\mu)\geq\lambda`$ となることである。

ネットが **普遍ネット** であるとは、任意の部分集合 $`A\subseteq X`$ について、$`A`$ またはその補集合のいずれかに最終的に含まれることである。
選択公理の下では、任意のネットは普遍部分ネットをもつ。

## 収束と集積点

位相空間 $`X`$ のネット $`(x_\lambda)`$ が点 $`x`$ に **収束** するとは、$`x`$ の任意の近傍に最終的に含まれることである。

点 $`x`$ がネットの **集積点** であるとは、$`x`$ の任意の近傍にネットがしばしば含まれることである。
これは、$`x`$ に収束する部分ネットが存在することと同値である。

部分集合 $`A\subseteq X`$ と点 $`x\in X`$ に対し、$`x`$ が $`A`$ の閉包に属することは、$`A`$ の点からなる $`x`$ へ収束するネットが存在することと同値である。
近傍系については [近傍系](./neighbourhood_system.md) を参照されたい。
