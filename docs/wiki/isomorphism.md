# 同型射

## 定義

> [!definition] 同型射
> 圏 $`\mathcal{C}`$ の射 $`f\colon A\to B`$ が **同型射** (*isomorphism*) であるとは、$`f`$ が[逆射](./inverse_morphism.md)を持つことである。

このとき、$`f^{-1}`$ で表される逆射を $`f`$ の逆射という。

> [!definition] 同型
> 圏 $`\mathcal{C}`$ の対象 $`A,B`$ の間に同型射 $`A\to B`$ が存在するとき、$`A`$ と $`B`$ は**同型** (*isomorphic*) であるといい、$`A\cong B`$ と表す。

対象の間の同型は、恒等射、同型射の合成、同型射の逆射によって、対象全体の同値関係を定める。

## 例

集合の圏 $`\mathsf{Set}`$ では、同型射は全単射に一致する。

群の圏 $`\mathsf{Grp}`$ では、同型射は群同型写像に一致する。

ベクトル空間の圏では、同型射は逆線形写像を持つ線形写像に一致する。
