# 定値射

定値射は、合成した射が一方の変数に依存しないという性質をもつ射である。

## 定義

> [!definition] 左定値射と右定値射
> 射 $`f\colon A\to B`$ が **左定値射** であるとは、任意の対象 $`X`$ と任意の二射 $`x,x'\colon X\to A`$ に対して
>
> ```math
> f\circ x=f\circ x'
> ```
>
> が成り立つことである。
> 双対的に、任意の $`y,y'\colon B\to Y`$ に対して $`y\circ f=y'\circ f`$ が成り立つとき、$`f`$ を **右定値射** という。

左定値かつ右定値な射を、この文脈で零射と呼ぶことがある。
ただし、通常の零射圏における零射は、対象対ごとに整合的に指定された射の族を指す。

## 例

零対象 $`0`$ をもつ圏では、合成

```math
A\longrightarrow0\longrightarrow B
```

は左定値かつ右定値である。
零対象については [零対象](./zero_object.md) を参照されたい。
