# Dedekind 整域

Dedekind 整域は、代数的整数論に現れる整数環を抽象化した整域である。
非零イデアルの一意分解をもつことが特徴である。

## 定義

> [!definition] Dedekind 整域
> **Dedekind 整域**とは、Noether 整域かつ整閉であり、Krull 次元が $`1`$ 以下である整域をいう。

体でない Dedekind 整域の非零素イデアルはすべて極大イデアルである。

## イデアル分解

Dedekind 整域 $`R`$ では、任意の非零真イデアル $`I`$ は非零素イデアルの積として表される。
この表示は因子の順序を除いて一意である。

また、$`R`$ の非零分数イデアルは可逆であり、積に関してアーベル群をなす。
主分数イデアルで割った商群をイデアル類群といい、主イデアル性からのずれを測る。

## 例

主イデアル整域は Dedekind 整域である。
代数体の整数環は Dedekind 整域であり、一般には主イデアル整域ではない。

整域の基本概念については [整域](./integral_domain.md) を、Noether 性については [Noether 環](./noetherian_ring.md) を参照されたい。
