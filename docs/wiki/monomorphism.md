# モノ射

集合の単射性は、写像の元を用いて定義される。
一般の圏では元を使えないため、射の合成に関する左消去則によって対応する概念を定める。

## 定義

> [!definition] モノ射
> 圏 $`\mathcal{C}`$ の射 $`f\colon A\to B`$ が **モノ射** (*monomorphism*) であるとは、任意の対象 $`X`$ と任意の射 $`x,x'\colon X\to A`$ に対して
>
> ```math
> f\circ x=f\circ x'\quad\Longrightarrow\quad x=x'
> ```
>
> が成り立つことをいう。

すなわち、任意の $`X`$ に対する写像 $`\mathcal{C}(X,A)\to\mathcal{C}(X,B)`$、$`x\mapsto f\circ x`$ が単射であることと同値である。
記号 $`\rightarrowtail`$ を用いて $`f\colon A\rightarrowtail B`$ と書くことがあるが、これはモノ射であるという性質を表す記法である。

## 例と非例

圏 $`\mathsf{Set}`$ では、モノ射は通常の単射に一致する。
実際、単射であれば任意の二写像の合成を左から消去でき、単射でなければ一点集合からの二つの写像を用いて消去則が破れる。

圏 $`\mathsf{Grp}`$ でも、モノ射は単射な群準同型に一致する。
ただし一般の圏では、モノ射を集合論的単射と同一視できない。
たとえば可換環と単位元を保つ環準同型の圏では、$`\mathbb{Z}\to\mathbb{Q}`$ はモノ射であるが、圏の内部で「元の単射性」を定義しているわけではない。

## 分裂モノ射と等化子

射 $`i\colon A\to B`$ が $`r\colon B\to A`$ に対して $`r\circ i=1_A`$ を満たすとき、$`i`$ を **断面** または**分裂モノ射**という。
このとき $`i`$ はモノ射である。
実際、$`i\circ x=i\circ x'`$ に左から $`r`$ を合成すれば $`x=x'`$ を得る。

二つの平行射の等化子もモノ射である。
これは、等化子の一意性が、その射を通る因子化の一意性を与えるためである。

反対圏でモノ射になる射は [エピ射](./epimorphism.md) である。
したがって、エピ射に関する命題は反対圏を通じてモノ射に関する双対命題を与える。
