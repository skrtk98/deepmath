# 連続写像

## 定義

> [!definition] 連続写像
> 位相空間 $`X,Y`$ の間の写像 $`f\colon X\to Y`$ が **連続** (*continuous*) であるとは、$`Y`$ の任意の開集合 $`V`$ に対して、逆像 $`f^{-1}(V)`$ が $`X`$ の開集合となることである。

同値に、$`Y`$ の任意の閉集合 $`C`$ に対して、$`f^{-1}(C)`$ が $`X`$ の閉集合となるとき、$`f`$ は連続である。

## 基本的な性質

恒等写像は連続である。

また、連続写像の合成は連続である。

全単射な連続写像であって、逆写像も連続であるものを同相写像という。

## 例

集合 $`X`$ が離散位相を持つとき、任意の写像 $`X\to Y`$ は連続である。

集合 $`Y`$ が密着位相を持つとき、任意の写像 $`X\to Y`$ は連続である。
