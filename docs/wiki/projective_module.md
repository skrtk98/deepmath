# 射影加群

## 定義

> [!definition] 射影加群
> 可換環 $`R`$ 上の加群 $`P`$ が **射影加群** (*projective module*) であるとは、任意の全射線形写像 $`q\colon M\twoheadrightarrow N`$ と任意の線形写像 $`f\colon P\to N`$ に対して、
> ```math
> q\circ\widetilde f=f
> ```
> を満たす線形写像 $`\widetilde f\colon P\to M`$ が存在することである。

すなわち、$`P`$ からの線形写像は任意の全射に沿って持ち上げられる。

## 同値な特徴付け

加群 $`P`$ が射影加群であることと、ある自由 $`R`$-加群 $`F`$ および $`R`$-加群 $`Q`$ が存在して
```math
F\cong P\oplus Q
```
と表せることは同値である。

したがって、自由加群は射影加群である。

## 例

任意の整数 $`n\ge0`$ に対して、$`R^n`$ は自由加群であるから射影加群である。

主イデアル整域上の有限生成射影加群は自由加群である。
