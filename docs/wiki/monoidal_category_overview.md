# モノイダル圏論の見取り図

モノイダル圏は、圏にテンソル積と単位対象を加え、対象や射を結合する操作を扱う。
ベクトル空間のテンソル積、集合や位相空間の直積、量子系の合成は代表的な例である。

## 学習の順序

[モノイダル圏](./monoidal_category.md) で結合子と単位子を確認し、[強モノイダル函手](./monoidal_functor.md) と [モノイダル自然変換](./monoidal_natural_transformation.md) へ進む。
その後、[組紐モノイダル圏](./braided_monoidal_category.md)、[対称モノイダル圏](./symmetric_monoidal_category.md)、[閉モノイダル圏](./closed_monoidal_category.md)、[双対対象](./dual_object.md) を学ぶ。
[モノイド対象](./monoid_object.md)、加群対象、トレースは、代数的および計算論的な応用を与える。
