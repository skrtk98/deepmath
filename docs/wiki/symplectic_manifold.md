# シンプレクティック多様体

シンプレクティック多様体は、閉かつ非退化な 2-形式を備えた滑らか多様体である。

## 定義

> [!definition] シンプレクティック多様体
> **シンプレクティック多様体**とは、滑らか多様体 $`M`$ と 2-形式 $`\omega\in\Omega^2(M)`$ の組 $`(M,\omega)`$ であって、
>
> ```math
> d\omega=0
> ```
>
> を満たし、各 $`p\in M`$ で双線形形式 $`\omega_p`$ が非退化であるものをいう。

非退化性とは、$`\omega_p(v,w)=0`$ がすべての $`w\in T_pM`$ に対して成り立つなら $`v=0`$ となることである。
従って、シンプレクティック多様体の次元は偶数である。

## 例

$`\mathbb{R}^{2n}`$ は

```math
\omega_0=\sum_{i=1}^n dx_i\wedge dy_i
```

によりシンプレクティック多様体となる。

余接束 $`T^*Q`$ は標準 1-形式 $`\theta`$ をもち、$`-d\theta`$ は標準シンプレクティック形式である。
微分形式については [微分形式](./differential_form.md) を、余接束については [余接束](./cotangent_bundle.md) を参照されたい。
