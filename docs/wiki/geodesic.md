# 測地線

測地線は、接続に関する速度ベクトルの共変微分が零となる曲線である。

## 定義

> [!definition] 測地線
> アフィン接続 $`\nabla`$ をもつ多様体 $`M`$ 上の滑らかな曲線 $`\gamma\colon I\to M`$ が **測地線** であるとは、
>
> ```math
> \nabla_{\dot\gamma(t)}\dot\gamma(t)=0
> ```
>
> がすべての $`t\in I`$ で成り立つことである。

局所座標では、この方程式は

```math
\frac{d^2x^k}{dt^2}
+
\sum_{i,j}\Gamma^k_{ij}(\gamma(t))
\frac{dx^i}{dt}\frac{dx^j}{dt}
=0
```

となる。

## 初期値と完備性

任意の点 $`p\in M`$ と接ベクトル $`v\in T_pM`$ に対し、$`\gamma(0)=p`$, $`\dot\gamma(0)=v`$ を満たす測地線は局所的に一意に存在する。

Riemann 多様体が測地的完備であるとは、すべての測地線が実数全体で定義されることである。
連結 Riemann 多様体では、測地的完備性は距離空間としての完備性と同値であり、任意の二点を結ぶ最短測地線の存在と関係する。
これは Hopf–Rinow 定理の内容である。
