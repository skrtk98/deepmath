# 導来関手

## 定義

> [!definition] 導来関手
> 左完全加法函手に入射解消を適用し、その複体のホモロジーを取って得られる函手を右導来関手という。
> 双対に、右完全加法函手に射影解消を適用して得られる函手を左導来関手という。

導来関手は、元の函手が完全でない度合いをホモロジーとして記録する。

## 構成と性質

左完全加法函手 $`F`$ と対象 $`A`$ の入射解消 $`A\to I^\bullet`$ に対し、右導来関手を $`R^nF(A)=H^n(F(I^\bullet))`$ と定める。
双対に、右完全加法函手の左導来関手は射影解消を用いて定める。

十分な入射対象または射影対象をもつアーベル圏では、導来関手は解消の選択に依らず定まる。
短完全系列からは、導来関手に関する長完全系列が得られる。

代表例は [Ext と Tor](./ext_and_tor.md) である。
