# 微分形式

## 定義

> [!definition] 微分形式
> 滑らか多様体 $`M`$ 上の $`k`$-形式とは、余接束の $`k`$ 次外冪の滑らかな切断である。
> $`k`$-形式全体を $`\Omega^k(M)`$ と表す。

> [!definition] 外微分
> 外微分とは、$`d\colon\Omega^k(M)\to\Omega^{k+1}(M)`$ として定まる線形写像の族であり、Leibniz 則と $`d\circ d=0`$ を満たすものである。

滑らかな関数 $`f`$ に対して、$`df`$ は 1-形式である。

面積形式と体積形式は高次の微分形式の例である。
外微分の性質により $`(\Omega^\bullet(M),d)`$ はコチェイン複体となり、Stokes の定理は微分形式の積分と外微分を結ぶ。
