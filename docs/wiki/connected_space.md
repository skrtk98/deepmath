# 連結空間

## 定義

> [!definition] 連結空間
> 位相空間 $`X`$ が **連結** であるとは、互いに素な二つの空でない開集合 $`U,V`$ で $`X=U\cup V`$ と表せないことである。

同値に、$`X`$ の開かつ閉な部分集合が $`\varnothing`$ と $`X`$ のみであるとき、$`X`$ は連結である。

## 性質

連結空間の連続像は連結である。

連結部分集合族が共通の一点を持つとき、それらの和集合は連結である。

## 例

実数直線の区間は連結である。

有理数全体 $`\mathbb{Q}`$ は通常の位相について連結ではない。
