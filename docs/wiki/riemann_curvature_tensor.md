# Riemann 曲率テンソル

## 定義

> [!definition] Riemann 曲率テンソル
> Riemann 多様体の Levi-Civita 接続を $`\nabla`$ とする。
> Riemann 曲率テンソルは、ベクトル場 $`X,Y,Z`$ に対して
> ```math
> R(X,Y)Z=\nabla_X\nabla_YZ-\nabla_Y\nabla_XZ-\nabla_{[X,Y]}Z
> ```
> により定める。

このテンソルは、共変微分が可換でない度合いを表す。
