# 準圏

## 定義

> [!definition] 準圏
> 単体集合 $`\mathcal{C}`$ が **準圏** (*quasi-category*) であるとは、任意の $`n\ge2`$ および $`0<i<n`$ に対して、内角 $`\Lambda_i^n\to\mathcal{C}`$ が単体写像 $`\Delta^n\to\mathcal{C}`$ へ拡張できることである。

この内角充填条件は、射の合成が一意な射ではなく、コヒーレントな高次ホモトピーを伴って与えられることを表す。

## 例

通常の圏の神経は準圏である。

神経がすべての角に対する充填条件を満たすとき、元の圏は群oidである。
