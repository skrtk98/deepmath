# 同相写像

同相写像は、開集合の構造を完全に保存する位相空間の同型である。

## 定義

> [!definition] 同相写像
> 連続写像 $`f\colon X\to Y`$ が **同相写像** であるとは、$`f`$ が全単射であり、逆写像 $`f^{-1}\colon Y\to X`$ も連続であることである。
> 同相写像が存在するとき、$`X`$ と $`Y`$ は **同相** であるという。

同相写像の合成と逆写像は同相写像である。

## 判定法

全単射な連続写像が開写像または閉写像であれば、その逆写像は連続である。
従って、その写像は同相写像である。

コンパクト空間から Hausdorff 空間への連続全単射も同相写像である。
この場合、写像は閉写像となる。

連続性については [連続写像](./continuous_map.md) を、開写像と閉写像については [開写像](./open_map.md) および [閉写像](./closed_map.md) を参照されたい。
