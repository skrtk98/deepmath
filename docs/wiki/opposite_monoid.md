# 反対モノイド

## 定義

> [!definition] 反対モノイド
> モノイド $`M`$ に対して、同じ集合上の演算を
> ```math
> a\ast b\coloneqq ba
> ```
> により定めて得られるモノイドを、$`M`$ の **反対モノイド** (*opposite monoid*) といい、$`M^{\mathrm{op}}`$ と表す。

$`M^{\mathrm{op}}`$ の単位元は $`M`$ の単位元 $`1_M`$ と一致する。

## 性質

反対モノイドを二度とると、標準的に元のモノイドに戻る。

```math
\left(M^{\mathrm{op}}\right)^{\mathrm{op}}=M
```

モノイド $`M`$ が可換であるとき、$`M^{\mathrm{op}}=M`$ である。

## 例

自己写像全体のモノイドでは、反対モノイドの積は写像の合成順序を反転させる。
