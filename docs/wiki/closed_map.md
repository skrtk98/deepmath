# 閉写像

閉写像は、閉集合の像が閉集合となる写像である。
連続性が閉集合の逆像を扱う条件であるのに対し、閉写像性は像を扱う条件である。

## 定義と判定

> [!definition] 閉写像
> 位相空間 $`X,Y`$ の間の写像 $`f\colon X\to Y`$ が **閉写像** であるとは、$`X`$ の任意の閉集合 $`F`$ に対して $`f(F)`$ が $`Y`$ の閉集合となることである。

閉写像の合成は閉写像である。
また、$`f`$ が閉写像であることは、任意の開集合 $`G\subseteq X`$ に対して

```math
\{y\in Y\mid f^{-1}(\{y\})\subseteq G\}
```

が開集合であることと同値である。
この集合は $`Y\setminus f(X\setminus G)`$ に等しい。

## 連続写像との関係

閉写像は連続であるとは限らず、連続写像も閉写像であるとは限らない。
ただし、コンパクト空間から Hausdorff 空間への連続写像は閉写像である。
