# 局所同相写像

局所同相写像は、各点の近傍に制限すれば同相写像となる連続写像である。

## 定義

> [!definition] 局所同相写像
> 連続写像 $`f\colon X\to Y`$ が **局所同相写像** であるとは、任意の $`x\in X`$ に対して開近傍 $`U\subseteq X`$ が存在し、$`f(U)`$ が $`Y`$ の開集合であり、制限写像
>
> ```math
> f|_U\colon U\longrightarrow f(U)
> ```
>
> が同相写像となることである。

局所同相写像は開写像である。
実際、開集合を局所同相となる近傍との交わりに分ければ、その像は開集合の和として表される。

局所同相写像は大域的な単射性や全射性を要求しない。
被覆写像は、さらに各点の近傍上で逆像全体が同相なシートに分解される局所同相写像である。
