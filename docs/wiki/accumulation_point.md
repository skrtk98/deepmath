# 集積点

集合自身の一点を除いても近傍に残る点を**集積点**または極限点という。

## 定義

> [!definition] 集積点
> 位相空間 $`X`$ の部分集合 $`A`$ と点 $`x`$ に対し、$`x`$ が $`A\setminus\{x\}`$ の [触点](./cluster_point.md) であるとき、$`x`$ を $`A`$ の集積点という。
> 集積点全体を $`A^d`$ と書き、導集合という。

したがって、$`x`$ が集積点であることは、任意の $`x`$ の近傍が $`x`$ と異なる $`A`$ の点を含むことと同値である。
