# 余米田の補題

余米田の補題は、前層を表現可能前層から復元する公式である。
この公式は、前層圏における余極限の記述に用いられる。

## 定理

> [!theorem] 余米田の補題
> 小圏 $`\mathcal{C}`$ と前層 $`F\colon\mathcal{C}^{\mathrm{op}}\to\mathsf{Set}`$ に対し、前層の自然同型
>
> ```math
> F \cong \int^{a\in\mathcal{C}} F(a) \times \mathcal{C}(-,a)
> ```
>
> が成り立つ。
> 右辺で $`\mathcal{C}(-,a)=y(a)`$ は対象 $`a`$ が表す表現可能前層であり、積とコエンドは前層圏で取る。

対象 $`X\in\mathcal{C}`$ における右辺の値は

```math
\int^{a\in\mathcal{C}} F(a)\times\mathcal{C}(X,a)
```

である。
この集合の元 $`(s,f)`$ は、$`s\in F(a)`$ と射 $`f\colon X\to a`$ の組である。
同型はこの組を制限写像による元 $`F(f)(s)\in F(X)`$ に送る。
コエンドの同一視は、射 $`g\colon a\to b`$ に対して $`(F(g)(t),f)`$ と $`(t,g\circ f)`$ を同一視するため、この写像は良定義である。
コエンドの一般的な定義は [エンドとコエンド](./end_and_coend.md) を参照されたい。

## 表現可能前層による表示

この定理は、任意の前層 $`F`$ が表現可能前層 $`y(a)`$ の余極限として標準的に表示されることを示す。
係数となる集合 $`F(a)`$ は、前層 $`F`$ に含まれる $`a`$ 型の元を表す。
コエンドは、射に沿う制限と表現可能前層の射を両立させるように、これらのコピーを貼り合わせる。

米田の補題が、表現可能前層から前層の値 $`F(a)`$ を復元する対応

```math
\operatorname{Nat}(y(a),F)\cong F(a)
```

を与えるのに対し、余米田の補題は、それらの値全体から前層 $`F`$ 自体を復元する。
米田の補題については [米田の補題](./yoneda_lemma.md) を、前層圏については [前層圏](./presheaf.md) を参照されたい。
