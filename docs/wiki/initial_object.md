# 始対象

任意の対象への射がただ一つに定まる対象は、空の入力から得られる普遍構成を表す。
この対象を **始対象** (*initial object*) という。

## 定義

> [!definition] 始対象
> 圏 $`\mathcal{C}`$ の対象 $`0`$ が **始対象** であるとは、任意の対象 $`X\in\mathcal{C}`$ に対して Hom 集合 $`\mathcal{C}(0,X)`$ がただ一つの元からなることをいう。
>
> すなわち、任意の $`X`$ にただ一つの射 $`0\to X`$ が存在する。

始対象の定義は [終対象](./terminal_object.md) の双対である。
始対象は、空図式の [余極限](./colimit.md) とみなせる。

## 例

圏 $`\mathsf{Set}`$ の空集合 $`\varnothing`$ は始対象である。
空集合から任意の集合への写像はただ一つである。

単位元を保つ環準同型を射とする圏では、整数環 $`\mathbb{Z}`$ が始対象である。
任意の環 $`R`$ に対し、$`1\mapsto1_R`$ を満たす環準同型 $`\mathbb{Z}\to R`$ は一意に定まる。

半順序を圏とみなした場合、始対象は最小元に一致する。
実際、$`0\leq x`$ が全ての $`x`$ に成り立つことは、$`0`$ から各 $`x`$ への一意な射があることに等しい。

## 一意性

始対象 $`0`$ と $`0'`$ が存在すれば、始対象の性質から一意な射 $`u\colon0\to0'`$ と $`v\colon0'\to0`$ が存在する。
合成 $`v\circ u`$ と $`1_0`$ はともに $`0\to0`$ の射であるから一致する。
同様に $`u\circ v=1_{0'}`$ である。
したがって、始対象は存在すれば [同型](./isomorphism.md) を除いて一意である。
