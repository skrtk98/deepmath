# 始位相

ここでいう弱位相は、写像族により定まる始位相を指す。
関数解析における連続双対が定める弱位相とは区別する。

## 定義

写像族 $`f_\lambda\colon Y\to X_\lambda`$ に対し、各 $`f_\lambda`$ を連続にする $`Y`$ 上の最も粗い位相を **始位相** またはこの文脈で弱位相という。

この位相は部分基

```math
\{f_\lambda^{-1}(G)\mid G\subseteq X_\lambda\text{ は開}\}
```

で生成される。

位相空間 $`Z`$ と写像 $`g\colon Z\to Y`$ に対し、$`g`$ が始位相に関して連続であることは、すべての $`f_\lambda\circ g`$ が連続であることと同値である。

積位相は射影写像族による始位相の例である。
