# 平坦加群

テンソル積が単射性を壊さない加群を**平坦加群**という。

## 定義

> [!definition] 平坦加群
> $`R`$-加群 $`M`$ が平坦であるとは、函手 $`-\otimes_RM`$ が短完全系列の左完全性を保つことをいう。
> 同値に、任意の単射 $`A\hookrightarrow B`$ に対して $`A\otimes_RM\to B\otimes_RM`$ が単射であることをいう。

平坦性は $`\operatorname{Tor}_1^R(-,M)=0`$ によって特徴づけられる。
これは [Tor](./ext_and_tor.md) がテンソル積の完全性の失敗を測ることの正確な形である。

自由加群と射影加群は平坦である。
局所化 $`S^{-1}R`$ は $`R`$-加群として平坦であり、体上の任意の加群も平坦である。
