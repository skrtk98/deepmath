# ホモロジー

ホモロジーは、鎖複体における閉鎖鎖を境界で割ることにより、空間や代数的対象の穴を測る。

## 定義

> [!definition] ホモロジー群
> 鎖複体 $`(C_\bullet,d)`$ の $`n`$ 次 **ホモロジー群** を
>
> ```math
> H_n(C_\bullet)
> =
> \ker(d_n)\big/\operatorname{im}(d_{n+1})
> ```
>
> と定める。

分子の元を $`n`$-サイクル、分母の元を $`n`$-バウンダリーという。
鎖複体の条件 $`d_n\circ d_{n+1}=0`$ により、分母は分子の部分群となる。

位相空間 $`X`$ に特異鎖複体を対応させて得られる群を、$`X`$ の特異ホモロジー群 $`H_n(X)`$ という。

## 性質

連続写像は特異ホモロジー群の準同型を誘導する。
ホモトピックな写像が誘導する準同型は一致するため、特異ホモロジー群はホモトピー不変量である。

鎖複体の定義については [鎖複体](./chain_complex.md) を参照されたい。
