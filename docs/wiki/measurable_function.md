# 可測関数

可測関数は、可測集合の逆像が可測となる写像である。

## 定義

> [!definition] 可測関数
> 可測空間 $`(X,\mathcal{F})`$, $`(Y,\mathcal{G})`$ の間の写像 $`f\colon X\to Y`$ が **可測** であるとは、任意の $`A\in\mathcal{G}`$ に対して
>
> ```math
> f^{-1}(A)\in\mathcal{F}
> ```
>
> が成り立つことである。

実数値関数では、終域に Borel $`\sigma`$-代数を入れることが多い。

## 例と性質

連続写像 $`f\colon\mathbb{R}\to\mathbb{R}`$ は Borel 可測である。
可測集合 $`A\subseteq X`$ の指示関数 $`\mathbf{1}_A`$ も可測である。

実数値可測関数の可算列が各点で収束するとき、その極限関数も可測である。
非負可測関数は単関数によって下から近似でき、Lebesgue 積分の定義に用いられる。
測度空間については [測度空間](./measure_space.md) を参照されたい。
