# ベクトル束

## 定義

> [!definition] ベクトル束
> 位相空間 $`M`$ 上の階数 $`r`$ のベクトル束とは、連続写像 $`\pi\colon E\to M`$ であって、各繊維 $`E_x=\pi^{-1}(x)`$ が $`r`$ 次元ベクトル空間となり、各 $`x\in M`$ が、$`\pi^{-1}(U)`$ と $`U\times\mathbb{R}^r`$ の間の繊維ごとの線形同相を与える開近傍 $`U`$ を持つものである。

この同相を局所自明化という。

## 例

滑らか多様体 $`M`$ の接束 $`TM`$ と余接束 $`T^*M`$ はベクトル束である。
