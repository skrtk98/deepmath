# 豊穣稠密性

豊穣稠密性は、豊穣函手の像から対象を標準的な重み付き余極限として再構成できることを表す。
豊穣米田埋め込み、各点 Kan 拡張、前層の表現可能前層による表示は、この概念の代表例である。

以下で $`\mathcal{V}`$ を対称モノイダル閉圏、$`A,C`$ を $`\mathcal{V}`$-圏、$`K\colon A\to C`$ を豊穣函手とする。

## 標準的な重み付き余極限

$`c\in C`$ に対し、豊穣 Hom により前層

```math
C(K-,c)\colon A^{\mathrm{op}}\longrightarrow\mathcal{V}
```

が定まる。
対応する重み付き余極限が存在すれば、評価射から標準射

```math
C(K-,c)\star K\longrightarrow c
```

が得られる。
この射は、$`K`$ の像から $`c`$ を復元するための比較射である。

> [!definition] 豊穣稠密函手
> $`K`$ が **豊穣稠密** であるとは、各 $`c\in C`$ に対して上の標準射が同型であることである。

この定義では、余極限に用いる重み $`C(K-,c)`$ が対象 $`c`$ ごとに定まる。
したがって、稠密性は単に $`K`$ の像が多くの対象を含むことではなく、像からの復元が Hom 対象と両立することを要請する。

## 制限米田函手による判定

$`K`$ に沿って米田前層を制限すると、豊穣函手

```math
N_K\colon C\longrightarrow[A^{\mathrm{op}},\mathcal{V}],
\qquad
c\longmapsto C(K-,c)
```

が得られる。
これは **制限米田函手** または $`K`$ に関する nerve と呼ばれる。

> [!theorem] 豊穣稠密性の判定
> 必要な重み付き余極限が存在すると仮定する。
> このとき $`K`$ が豊穣稠密であることと、制限米田函手 $`N_K`$ が充満忠実であることは同値である。

同値な Kan 拡張による記述として、$`C`$ の米田埋め込みを $`y_C`$ とすると

```math
y_C
\cong
\operatorname{Lan}_K(y_CK)
```

が成り立つ。
この式は、$`C`$ の Hom 前層が $`K`$ 上の値から左 Kan 拡張によって復元されることを表す。

## 米田埋め込みの例

豊穣米田埋め込み

```math
y\colon A\longrightarrow[A^{\mathrm{op}},\mathcal{V}]
```

は豊穣稠密である。
実際、豊穣前層 $`F`$ は表現可能前層により

```math
F\cong\int^{a\in A}F(a)\odot y(a)
```

と表示される。
これは $`F`$ が重み $`F`$ を用いる $`y`$ の像の重み付き余極限であることを示す。

重みが絶対であることは、Cauchy 完成に関わるより強い条件であり、一般の稠密性からは従わない。
絶対重みと小射影前層については [豊穣 Cauchy 完成](./enriched_cauchy_completion.md) を参照されたい。

豊穣米田の補題は [豊穣米田の補題](./enriched_yoneda_lemma.md) を、左 Kan 拡張の各点公式は [豊穣 Kan 拡張](./enriched_kan_extension.md) を、重み付き余極限の定義は [重み付き余極限](./weighted_colimit_enriched.md) を参照されたい。
