# 余核

射の像を零射へ潰すための普遍的な射を**余核**という。
余核は核の反対圏における双対概念である。

## 定義

> [!definition] 余核
> 零射をもつ圏において、射 $`f\colon A\to B`$ の **余核** とは、射 $`q\colon B\to Q`$ であって $`q\circ f=0_{A,Q}`$ を満たし、この条件を満たす任意の射 $`q'\colon B\to Q'`$ が一意な射 $`v\colon Q\to Q'`$ により $`v\circ q=q'`$ と因子化するものをいう。

余核は $`f`$ と零射 $`0_{A,B}`$ の余等化子である。
したがって余核は [エピ射](./epimorphism.md) であり、存在すれば同型を除いて一意である。

## 例

$`\mathsf{Ab}`$ では、群準同型 $`f\colon A\to B`$ の余核は商群 $`\operatorname{coker}f=B/\operatorname{Im}f`$ と自然な射影で与えられる。
加群の圏およびベクトル空間の圏でも同じ商構成が余核となる。

余核の双対概念は [核](./kernel.md) である。
