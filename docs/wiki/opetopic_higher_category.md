# Opetopic 高次圏

オペトープは、高次の合成と貼り合わせの形状を記述する組合せ的図形である。

## 概要

1 次元では、有限列の矢印が合成の形状を与える。
高次では木とその反復構成が合成の形状を与え、オペトープはこの形状を各次元で生成する。

**opetopic $`n`$-圏** は、各オペトープ形状に対応するセルと、境界、充填、貼り合わせ、単位に関する条件からなる高次圏モデルである。
コヒーレンスは、必要な高次セルの充填条件として表される。

この記述では、合成を行う順序と形状を同時に追跡できる。
圏化との関係については [圏化](./categorification.md) を、高次圏の他のモデルについては [高次圏論](./higher_category_theory.md) を参照されたい。
