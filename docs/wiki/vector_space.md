# ベクトル空間

## 定義

> [!definition] ベクトル空間
> 体 $`k`$ 上の **ベクトル空間** (*vector space*) とは、$`k`$ を環とみなしたときの $`k`$-加群である。

ベクトル空間 $`V`$ の元をベクトルといい、$`a\in k`$ と $`v\in V`$ に対する積 $`av`$ をスカラー倍という。

## 例

体 $`k`$ に対して、$`k^n`$ は成分ごとの加法とスカラー倍により $`k`$ 上のベクトル空間となる。

有限次元ベクトル空間 $`V`$ の基底の濃度は基底の選び方によらず一定であり、これを $`V`$ の次元と呼ぶ。
