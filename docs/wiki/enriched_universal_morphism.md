# 豊穣圏における普遍射

豊穣普遍射は、一意な因子化を集合の全単射ではなく Hom 対象の自然同型として記述する。
この構成は豊穣随伴の存在を対象ごとの表現可能性へ帰着する。

以下で $`\mathcal{V}`$ を [モノイダル圏](./monoidal_category.md)、$`T\colon A\to B`$ を $`\mathcal{V}`$-函手、$`b\in B`$ とする。

## $`b`$ から $`T`$ への普遍射

> [!definition] 豊穣普遍射
> 対象 $`a\in A`$ と 2 射に相当する $`\mathcal{V}`$ の射 $`u\colon I\to B(b,Ta)`$ の組が、$`b`$ から $`T`$ への **豊穣普遍射** であるとは、任意の $`x\in A`$ に $`\mathcal{V}`$ において自然な同型
>
> ```math
> A(a,x)\cong B(b,Tx)
> ```
>
> を与えることである。

この同型は $`u`$ による合成から定まる。
すなわち、左辺の Hom 対象の元は $`u`$ の後に $`T`$ が送る射を合成することにより、右辺の Hom 対象の元へ対応する。

双対的に、対象 $`a`$ と射 $`v\colon I\to B(Ta,b)`$ が、各 $`x\in A`$ に自然な同型

```math
A(x,a)\cong B(Tx,b)
```

を与えるとき、$`(a,v)`$ を $`T`$ から $`b`$ への豊穣普遍射という。

## 豊穣随伴との関係

> [!proposition] 豊穣随伴の存在判定
> 各 $`b\in B`$ に対して $`b`$ から $`T`$ への豊穣普遍射を選べることと、$`T`$ が豊穣左随伴をもつことは同値である。

実際、普遍射の対象を $`G(b)`$ と書けば、上の同型は

```math
A(Gb,x)\cong B(b,Tx)
```

となる。
これは $`G\dashv T`$ を表す Hom 対象の自然同型である。
双対的な普遍射は左随伴 $`T`$ の右随伴を与える。

$`\mathcal{V}=\mathsf{Set}`$ の場合、この定義は通常の普遍射に一致する。
通常の普遍射は [普遍性](./universal_property.md) を、豊穣随伴の Hom 対象による定義は [豊穣随伴と豊穣同値](./enriched_adjoint_equivalence.md) を参照されたい。
