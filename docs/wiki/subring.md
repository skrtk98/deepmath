# 部分環

## 定義

> [!definition] 部分環
> 環 $`R`$ の部分集合 $`S\subseteq R`$ が **部分環** (*subring*) であるとは、$`S`$ が $`R`$ の演算を制限して得られる環であり、包含写像 $`S\hookrightarrow R`$ が単位元を保つ環準同型となることである。
>
> 同値に、次の条件が成り立つ。
>
> - $`1_R\in S`$。
> - 任意の $`a,b\in S`$ に対して、$`a-b\in S`$ および $`ab\in S`$。

本ノートでは、特に断らない限り、$`1_S=1_R`$ を満たす部分環のみを扱う。

## 例

有理数体 $`\mathbb{Q}`$ は実数体 $`\mathbb{R}`$ の部分環である。

整数環 $`\mathbb{Z}`$ は有理数体 $`\mathbb{Q}`$ の部分環である。

行列環 $`M_n(R)`$ のスカラー行列全体は、$`R`$ が可換環であるとき $`R`$ と同型な部分環をなす。
