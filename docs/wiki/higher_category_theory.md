# 高次圏論

高次圏論は、射の間の射である 2-射と、そのさらに高次の射を扱う理論である。
合成則を等号ではなく高次の可逆射で比較することが中心となる。

## モデル

高次圏を表す代表的なモデルには、準圏、Segal 圏および complete Segal space、opetopic または globular な代数的モデルがある。
各モデルは合成と同値を異なるデータで表すため、計算や幾何学的用途に応じて使い分けられる。

適切なモデル構造を備え、Quillen 同値で結ばれる二つのモデルは同じホモトピー理論を提示する。
従ってモデル比較では、対象を文字通り同一視するのではなく、対応する同値型を比較する。

## 低次元との関係

厳密2圏は 2-射までの合成が等号で成り立つ高次構造である。
双圏では 1-射の結合律と単位律を可逆2-射で置き換える。
これらは高次圏の低次元の現れとして理解できる。

主要な話題には高次随伴、高次 Kan 拡張、直線化と逆直線化、$`\infty`$-トポス、$`(\infty,n)`$-圏のモデル比較がある。
準圏については [準圏](./quasi_category.md) を、擬函手については [擬函手](./pseudofunctor.md) を参照されたい。
