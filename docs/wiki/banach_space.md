# Banach 空間

## 定義

> [!definition] Banach 空間
> ノルム空間が、そのノルムから誘導される距離について完備であるとき、これを **Banach 空間** (*Banach space*) という。

すなわち、任意の Cauchy 列が空間内の元に収束するノルム空間が Banach 空間である。

## 例

有限次元ノルム空間は Banach 空間である。

連続関数空間 $`C([a,b])`$ は一様ノルムについて Banach 空間である。

一般に、$`1\leq p\leq\infty`$ に対する列空間 $`\ell^p`$ と、測度空間上の $`L^p(\mu)`$ は標準的な Banach 空間である。
コンパクト Hausdorff 空間 $`K`$ 上の連続関数空間 $`C(K)`$ も、一様ノルムについて Banach 空間である。

有限次元性は本質的でない。
たとえば有理数係数の多項式全体は一様ノルムについてノルム空間であるが、連続関数空間内で完備ではない。
