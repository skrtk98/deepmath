# Banach 空間

## 定義

> [!definition] Banach 空間
> ノルム空間が、そのノルムから誘導される距離について完備であるとき、これを **Banach 空間** (*Banach space*) という。

すなわち、任意の Cauchy 列が空間内の元に収束するノルム空間が Banach 空間である。

## 例

有限次元ノルム空間は Banach 空間である。

連続関数空間 $`C([a,b])`$ は一様ノルムについて Banach 空間である。
