# 終位相

ここでいう強位相は、写像族により定まる終位相を指す。
関数解析で用いる強位相とは区別する。

## 定義

写像族 $`f_\lambda\colon X_\lambda\to Y`$ に対し、各 $`f_\lambda`$ を連続にする $`Y`$ 上の最も細かい位相を **終位相** またはこの文脈で強位相という。

部分集合 $`U\subseteq Y`$ が終位相で開であることは、すべての $`\lambda`$ について $`f_\lambda^{-1}(U)` が $`X_\lambda`$ で開であることと同値である。

位相空間 $`Z`$ と写像 $`g\colon Y\to Z`$ に対し、$`g`$ が終位相に関して連続であることは、すべての $`g\circ f_\lambda`$ が連続であることと同値である。

商位相は商写像による終位相の例である。
