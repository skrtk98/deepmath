# レトラクション

射を合成して恒等射に戻せるとき、その射は対象の一方を他方の中の直和因子に似た形で分離する。
この状況を表す射が **レトラクション** (*retraction*) である。

## 定義

> [!definition] レトラクションと断面
> 射 $`r\colon B\to A`$ が **レトラクション** であるとは、ある射 $`i\colon A\to B`$ が存在して
>
> ```math
> r\circ i=1_A
> ```
>
> を満たすことをいう。
> このとき $`i`$ を $`r`$ の **断面** (*section*) といい、$`r`$ を **分裂エピ射**、$`i`$ を **分裂モノ射**ともいう。

この等式は次の可換図式で表される。

```tikz
\begin{tikzcd}[column sep=large]
A \arrow[r, "i"] \arrow[dr, "1_A"'] & B \arrow[d, "r"] \\
& A
\end{tikzcd}
```

## 性質

レトラクション $`r`$ は [エピ射](./epimorphism.md) であり、その断面 $`i`$ は [モノ射](./monomorphism.md) である。
この結論は、上の恒等式により合成の消去則を導くことで得られる。

レトラクションと断面の組 $`(r,i)`$ があっても、$`r`$ または $`i`$ が同型射であるとは限らない。
両方の向きの逆射条件、すなわち $`r\circ i=1_A`$ と $`i\circ r=1_B`$ がともに成り立つ場合に限り、両者は [同型射](./isomorphism.md) となる。

## 例

直積 $`X\times Y`$ が存在し、対象 $`Y`$ から終対象への射と両立する大域点 $`y_0\colon 1\to Y`$ が与えられているとする。
このとき第一射影 $`\pi_1\colon X\times Y\to X`$ は

```math
i\colon X\longrightarrow X\times Y,
\qquad
x\longmapsto (x,y_0)
```

を断面にもつのでレトラクションである。
圏 $`\mathsf{Set}`$ では、これは集合 $`Y`$ の元 $`y_0`$ を選び、$`x`$ を $`(x,y_0)`$ へ送る写像に対応する。

レトラクションをもつ対象 $`A`$ は $`B`$ の**レトラクト**と呼ばれる。
レトラクトは、対象の性質が直和因子や冪等射の分裂と関係する場面で用いられる。
