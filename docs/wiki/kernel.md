# 核

零射をもつ圏では、射が零射となる部分を普遍性で定められる。
この構成を**核**という。

## 定義

> [!definition] 核
> 零射をもつ圏において、射 $`f\colon A\to B`$ の **核** とは、射 $`k\colon K\to A`$ であって $`f\circ k=0_{K,B}`$ を満たし、この条件を満たす任意の射 $`k'\colon K'\to A`$ が一意な射 $`u\colon K'\to K`$ により $`k\circ u=k'`$ と因子化するものをいう。

すなわち、核は $`f`$ と零射 $`0_{A,B}`$ の [等化子](./equalizer.md) である。
したがって核は [モノ射](./monomorphism.md) であり、存在すれば同型を除いて一意である。

## 例

$`\mathsf{Ab}`$ では、群準同型 $`f\colon A\to B`$ の核は $`\ker f=\{a\in A\mid f(a)=0\}`$ と包含準同型で与えられる。
加群の圏およびベクトル空間の圏でも同じ記述が成り立つ。

核の双対概念は [余核](./cokernel.md) である。
