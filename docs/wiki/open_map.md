# 開写像

開写像は、開集合の像が開集合となる写像である。

## 定義と判定

> [!definition] 開写像
> 位相空間 $`X,Y`$ の間の写像 $`f\colon X\to Y`$ が **開写像** であるとは、$`X`$ の任意の開集合 $`G`$ に対して $`f(G)`$ が $`Y`$ の開集合となることである。

開写像の合成は開写像である。
また、$`f`$ が開写像であることは、任意の部分集合 $`S\subseteq Y`$ に対して

```math
f^{-1}(\overline{S})\subseteq\overline{f^{-1}(S)}
```

が成り立つことと同値である。

開写像は連続であるとは限らず、連続写像も開写像であるとは限らない。
