# 半圏

半圏は、圏から恒等射の存在を除いた構造である。
合成と結合律は定めるが、各対象に単位射を要求しない。

## 定義

> [!definition] 半圏
> **半圏** $`\mathcal{C}`$ は、対象の類 $`\mathcal{C}_0`$、射の類 $`\mathcal{C}_1`$、始域・終域写像
>
> ```math
> s,t\colon\mathcal{C}_1\to\mathcal{C}_0
> ```
>
> および、可換する対の射に対する合成からなる。
> すなわち $`t(f)=s(g)`$ のとき射 $`g\circ f`$ が定まり、
>
> ```math
> s(g\circ f)=s(f),\qquad t(g\circ f)=t(g)
> ```
>
> および結合律 $`(h\circ g)\circ f=h\circ(g\circ f)`$ を満たす。

各対象 $`x`$ に射 $`1_x\colon x\to x`$ が存在し、左右の単位律を満たす半圏は圏である。

## 例と単位化

一対象半圏は半群に一致する。
恒等射を除いた厳密縮小写像だけを射とする構成も、半圏の例となる。

任意の半圏には、各対象ごとに形式的な恒等射を自由に付加して圏を作ることができる。
この単位化は、圏から恒等射を忘れる函手の左随伴を与える。
圏の定義については [圏](./category.md) を参照されたい。
