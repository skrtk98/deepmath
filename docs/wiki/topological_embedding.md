# 位相的埋め込み

位相的埋め込みは、位相空間を別の位相空間の部分空間として同相に実現する写像である。

## 定義

> [!definition] 位相的埋め込み
> 連続写像 $`f\colon X\to Y`$ が **位相的埋め込み** であるとは、$`f`$ が単射であり、像に部分空間位相を与えたとき
>
> ```math
> f\colon X\longrightarrow f(X)
> ```
>
> が同相写像となることである。

位相的埋め込みを $`f\colon X\hookrightarrow Y`$ と書くことがある。
全単射な位相的埋め込みは同相写像である。

## 注意

二つの空間が互いの部分空間に同相であることから、その二つの空間が同相であるとは一般には結論できない。
位相的な Cantor–Bernstein 原理は一般には成立しないため、相互埋め込みだけでは同相性を判定できない。

部分空間位相については [部分空間](./topological_subspace.md) を参照されたい。
