# プロト圏

プロト圏は、射そのものを表す原射と、始点・終点および合成を指定する関係から圏を提示する形式である。
同じ原射が複数の Hom 集合に属し得ることを許すため、通常の Hom 集合による圏の定義よりも提示に関する情報を多く保持する。

## 定義

> [!definition] プロト圏
> **プロト圏**は、対象の類、原射の類、原射 $`f`$ と対象 $`A,B`$ の間の関係 $`f\colon A\to B`$、および合成を表す関係 $`h=g\circ f`$ からなる。
> 各対象対 $`A,B`$ に対して
>
> ```math
> \operatorname{Hom}(A,B)=\{f\mid f\colon A\to B\}
> ```
>
> と定めたとき、これらの Hom 集合と合成が結合律および単位律を満たすことを要請する。

この記法では、$`f\colon A\to B`$ は原射 $`f`$ と対象対の関係であって、原射の始点と終点が一意に定まることをあらかじめ仮定しない。

## 通常の圏との違い

通常の圏を射の全体の互いに素な和として表すと、各射は一意な始点と終点をもつ。
これに対しプロト圏では、異なる Hom 集合に現れる原射が同一であるという提示上の情報を残せる。

したがって、プロト圏は通常の圏と同値な単なる別定義ではない。
各 Hom 集合を互いに素にして通常の圏として扱う過程では、原射どうしの同一視に関する情報が失われる。

## 例

関数を順序対の集合として表すとき、同じ関数グラフを異なる余域をもつ写像として扱うことがある。
このような表現では、一つの原射が複数の対象対に関係付けられるため、プロト圏の形式が適する。

通常の圏における Hom 集合と合成は [圏](./category.md) を、射の始点と終点が一意に定まる場合の記述は [始点と終点](./source_and_target.md) を参照されたい。
