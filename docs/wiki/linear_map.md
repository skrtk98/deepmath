# 線形写像

## 定義

> [!definition] 線形写像
> 可換環 $`R`$ 上の加群 $`M,N`$ に対して、写像 $`f\colon M\to N`$ が **$`R`$-線形写像** (*$`R`$-linear map*) であるとは、任意の $`a\in R`$ および $`x,y\in M`$ に対して
> ```math
> f(x+y)=f(x)+f(y),\qquad f(ax)=af(x)
> ```
> を満たすことである。

ベクトル空間の間の線形写像は、体を係数環とする線形写像である。

## 基本的な性質

線形写像は零元を保つ。すなわち、$`f(0_M)=0_N`$ が成り立つ。

また、線形写像の合成は線形写像である。

全単射な線形写像を線形同型という。

## 例

可換環 $`R`$ 上の加群 $`M`$ に対して、恒等写像 $`\operatorname{id}_M\colon M\to M`$ は線形写像である。

体 $`k`$ 上のベクトル空間 $`k^n`$ から $`k^m`$ への線形写像は、$`m\times n`$ 行列によって表される。
