# 基本群

基本群は、基点を保つループを端点固定ホモトピーで同一視して得られる群である。

## 定義

点付き空間 $`(X,x_0)`$ の **ループ** とは、連続写像 $`\gamma\colon[0,1]\to X`$ であって $`\gamma(0)=\gamma(1)=x_0`$ を満たすものである。

> [!definition] 基本群
> ループの端点固定ホモトピー類全体に連結積による演算を入れて得られる群を、$`(X,x_0)`$ の **基本群** といい、
>
> ```math
> \pi_1(X,x_0)
> ```
>
> と書く。

恒等元は定値ループの類であり、逆元はループの向きを反転して得られる。

## 例と性質

```math
\pi_1(S^1)\cong\mathbb{Z},
\qquad
\pi_1(S^n)=0\ (n\geq2),
\qquad
\pi_1(T^2)\cong\mathbb{Z}^2.
```

基点を保つホモトピー同値は基本群の同型を誘導する。
連結、局所道連結、半局所単連結な空間では、連結被覆空間は基本群の部分群によって分類される。
被覆空間については [被覆空間](./covering_space.md) を参照されたい。
