# モノイダル基底上の豊穣圏論の見取り図

豊穣圏論は、通常の Hom 集合をモノイダル圏の対象へ置き換える。
この置換により、加法圏、線形圏、順序、Lawvere 距離空間を同じ圏論的形式で扱える。

## 学習の順序

基底の [モノイダル圏](./monoidal_category.md) と [閉モノイダル圏](./closed_monoidal_category.md) を確認した後、[豊穣圏](./enriched_category.md)、[豊穣函手](./enriched_functor.md)、[豊穣自然変換](./enriched_natural_transformation.md) を学ぶ。
次に [豊穣函手圏](./enriched_functor_category.md)、[豊穣米田の補題](./enriched_yoneda_lemma.md)、[重み付き余極限](./weighted_colimit_enriched.md)、[豊穣 Kan 拡張](./enriched_kan_extension.md) を扱う。
[Bénabou cosmos 上の豊穣圏](./benabou_cosmos_enrichment.md) は、これらの構成に十分な基底の仮定を整理する。
