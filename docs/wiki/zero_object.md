# 零対象

始対象と終対象が一つの対象に一致する圏では、任意の二対象の間に標準的な射を選べる。
この構造の基点となる対象を **零対象** (*zero object*) という。

## 定義

> [!definition] 零対象
> 圏 $`\mathcal{C}`$ の対象 $`0`$ が **零対象** であるとは、$`0`$ が [始対象](./initial_object.md) かつ [終対象](./terminal_object.md) であることをいう。

始対象と終対象のそれぞれの一意性により、零対象も存在すれば同型を除いて一意である。
文脈上混乱がなければ、零対象を同じ記号 $`0`$ で表す。

## 例

可換群の圏 $`\mathsf{Ab}`$ では、零群が零対象である。
零群から任意の可換群への準同型も、任意の可換群から零群への準同型も一意である。

体 $`k`$ 上のベクトル空間の圏 $`\mathsf{Vect}_k`$ では、零ベクトル空間が零対象である。
加群の圏、アーベル圏、鎖複体の圏にも同様に零対象がある。

一方、$`\mathsf{Set}`$ では空集合は始対象であり一点集合は終対象であるが、両者は同型ではない。
したがって $`\mathsf{Set}`$ は零対象をもたない。

## 零射

零対象 $`0`$ をもつ圏では、任意の対象 $`A,B`$ に対して

```math
A\longrightarrow0\longrightarrow B
```

という合成を取れる。
この合成を $`0_{A,B}\colon A\to B`$ と書き、$`A`$ から $`B`$ への**零射**という。
零対象の始・終性により、この射は選んだ零対象に依存しない。

零射は合成と両立する。
すなわち、適合する任意の射 $`f,g`$ に対して $`f\circ0=0`$ および $`0\circ g=0`$ が成り立つ。
この性質により、核と余核を「零射と等しくなる」という条件で定義できる。
