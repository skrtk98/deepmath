# Hom 集合

局所小圏では、二つの対象の間の射全体を集合として扱える。

## 定義と例

> [!definition] Hom 集合
> 局所小圏 $`\mathcal{C}`$ と対象 $`X,Y`$ に対し、$`X`$ から $`Y`$ への射の集合 $`\mathcal{C}(X,Y)`$ を Hom 集合という。

$`\mathsf{Set}`$ では Hom 集合は写像全体 $`Y^X`$ である。
$`\mathsf{Grp}`$ では群準同型全体である。
前順序を圏とみなす場合、$`x\leq y`$ なら Hom 集合は一点集合であり、そうでなければ空集合である。

豊穣圏では Hom は集合ではなく [Hom 対象](./enriched_category.md) となる。
閉モノイダル圏の内部 Hom 対象とも区別する。
