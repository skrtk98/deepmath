# モノイド

## 定義

> [!definition] モノイド
> **集合 $`M`$ 上のモノイド構造** (*monoid structure on a set $`M`$*) とは、以下のデータ
>
> - 二項演算 $`\cdot\colon M\times M\to M`$,
> - 単位元 $`e\in M`$,
>
> からなり、**モノイドの公理** (*monoid axioms*) と呼ばれる次の条件を満たすときいう：
>
> - 結合律：任意の $`a,b,c\in M`$ で $`(a\cdot b)\cdot c=a\cdot(b\cdot c)`$,
> - 単位律：任意の $`a\in M`$ で $`a\cdot e=e\cdot a=a`$,
>
> 集合 $`M`$ と $`M`$ 上のモノイド構造 $`(\,\cdot\,, e)`$ の組 $`(M; \,\cdot\,, e)`$ を**モノイド** (*monoid*) といい、集合 $`M`$ をこのモノイドの**台集合** (*underlying set*) という。

以下では、モノイド $`M`$ の単位元を $`1_M`$ と表す。

モノイドの演算記号 $`\cdot`$ は、混同のおそれがない限り省略して表す。

> [!proposition] 単位元の一意性
> モノイドにおいて単位元は一意である。
> すなわち、台集合と演算が一致するような任意の 2 つのモノイド $`(M;\,\cdot\,,e),(M;\,\cdot\,,e')`$ に対して $`e=e'`$ が成り立つ。

> [!proof]
> $`e`$ が単位元であることから $`e\cdot e'=e'`$、$`e'`$ が単位元であることから $`e\cdot e'=e`$。よって $`e=e'`$。
