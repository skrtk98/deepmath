# 圏論の見取り図

圏論は、対象の内部構造だけでなく、対象間の射とその合成を研究する言語である。
集合、群、環、位相空間、線形空間のように異なる対象を、射が保存する構造と普遍性によって比較できる。

## 学習の順序

まず [圏](./category.md)、[射の始点と終点](./source_and_target.md)、[函手](./functor.md)、[自然変換](./natural_transformation.md) を通じて、射と構造保存の記法を定める。
次に [普遍性](./universal_property.md)、[随伴函手](./adjoint_functor.md)、[極限](./limit.md)、[余極限](./colimit.md) を学ぶと、積、余積、等化子、引き戻しを共通の形式で扱える。
前層、米田埋め込み、Kan 拡張、高次圏論は、この基礎の上に位置する。
