# 圏化

圏化は、集合論的な構成を圏論的な構成へ持ち上げ、等式を同型へ置き換える考え方である。

## 基本対応

- 集合を圏へ置き換える。
- 関数を函手へ置き換える。
- 関数の等式を自然同型へ置き換える。

等式を同型へ弱めると、複数の同型を合成する方法が一意ではなくなる。
このずれを制御する条件がコヒーレンスである。
モノイダル圏の五角形公理と三角形公理はその典型例である。

## 例

自然数の加法と乗法は、有限集合の圏における互いに素な和と直積によって圏化される。
有限集合の同型類を取ると、その濃度は自然数となり、加法と乗法が回復される。
このように、圏から同型類などを取って集合論的な情報へ戻す操作を脱圏化という。

圏化を反復すると、2-圏、双圏、さらに高次圏が現れる。
モノイダル圏のコヒーレンスについては [モノイダル圏](./monoidal_category.md) を参照されたい。
