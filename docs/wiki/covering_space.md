# 被覆空間

被覆空間は、基礎空間を局所的には互いに素なコピーの和として表す空間である。

## 定義

> [!definition] 被覆写像
> 連続全射 $`p\colon\widetilde{X}\to X`$ が **被覆写像** であるとは、任意の $`x\in X`$ に対して開近傍 $`U`$ が存在し、
>
> ```math
> p^{-1}(U)=\coprod_{\alpha\in A}U_\alpha
> ```
>
> と互いに素な開集合の和に分解され、各制限 $`p|_{U_\alpha}\colon U_\alpha\to U`$ が同相写像となることである。
> このとき $`\widetilde X`$ を $`X`$ の **被覆空間** という。

被覆写像は局所同相写像である。

## 基本性質と例

被覆写像は経路持ち上げ性とホモトピー持ち上げ性をもつ。
適切な基点を選ぶと、持ち上げは一意に定まる。

円周への写像

```math
\mathbb{R}\longrightarrow S^1,
\qquad
t\longmapsto e^{2\pi i t}
```

は被覆写像である。
また、$`\mathbb{R}^2\to T^2`$ はトーラスの普遍被覆を与える。

基礎空間が連結、局所道連結、半局所単連結であれば、連結被覆空間は基本群の部分群によって分類される。
局所的な性質については [局所同相写像](./local_homeomorphism.md) を参照されたい。
