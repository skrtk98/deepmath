# フィルター付き圏

**フィルター付き圏** (*filtered category*) は、有限個の対象と射を十分先の一つの段階で同時に比較できる添字圏である。
フィルター付き余極限は、有向系による帰納極限を圏論的に一般化する。

## 定義

> [!definition] フィルター付き圏
> 小圏 $`I`$ が **フィルター付き** であるとは、次を満たすことである。
>
> - $`I`$ は空でない。
> - 任意の対象 $`i,j`$ に対し、射 $`i\to k`$ と $`j\to k`$ をもつ対象 $`k`$ が存在する。
> - 任意の平行射 $`u,v\colon i\rightrightarrows j`$ に対し、$`w\circ u=w\circ v`$ を満たす射 $`w\colon j\to k`$ が存在する。

反対圏がフィルター付きである圏を余フィルター付きという。

## 例と性質

有向半順序を圏とみなすとフィルター付き圏になる。
したがって、通常の有向系の帰納極限はフィルター付き余極限の例である。

$`\mathsf{Set}`$ ではフィルター付き余極限は有限極限と可換である。
この性質により、有限個の等式や有限個の生成元で表される構造を、段階的な余極限と両立させて扱える。
