# 終対象

任意の対象からの射がただ一つに定まる対象は、空図式に対する極限を表す。
この対象を **終対象** (*terminal object*) という。

## 定義

> [!definition] 終対象
> 圏 $`\mathcal{C}`$ の対象 $`1`$ が **終対象** であるとは、任意の対象 $`X\in\mathcal{C}`$ に対して Hom 集合 $`\mathcal{C}(X,1)`$ がただ一つの元からなることをいう。
>
> すなわち、任意の $`X`$ にただ一つの射 $`X\to1`$ が存在する。

終対象の定義は [始対象](./initial_object.md) の双対である。
終対象は、空図式の [極限](./limit.md) とみなせる。

## 例

圏 $`\mathsf{Set}`$ の一点集合は終対象である。
任意の集合から一点集合への写像はただ一つである。

圏 $`\mathsf{Top}`$ の一点空間も終対象である。
集合としての写像が一意であり、その写像は連続である。

半順序を圏とみなした場合、終対象は最大元に一致する。
実際、任意の $`x`$ に対して $`x\leq1`$ が成り立つことは、各 $`x`$ から $`1`$ への一意な射があることに等しい。

## 一意性と大域点

終対象 $`1`$ と $`1'`$ が存在すれば、終対象の性質により一意な射 $`u\colon1\to1'`$ と $`v\colon1'\to1`$ が存在する。
合成に終対象の一意性を適用すると、$`u`$ と $`v`$ は互いに逆射である。
したがって、終対象は存在すれば [同型](./isomorphism.md) を除いて一意である。

終対象 $`1`$ をもつ圏では、射 $`x\colon1\to X`$ を $`X`$ の**大域点**という。
圏 $`\mathsf{Set}`$ では、一点集合から $`X`$ への写像は $`X`$ の元を一つ選ぶことに一致する。
しかし一般の圏では、大域点が対象の全情報を捉えるとは限らない。
