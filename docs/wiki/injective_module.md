# 入射加群

単射に沿う加群準同型の延長を常に許す加群を**入射加群**という。

## 定義

> [!definition] 入射加群
> $`R`$-加群 $`I`$ が入射であるとは、任意の単射 $`A\hookrightarrow B`$ と準同型 $`A\to I`$ に対して、その写像を延長する準同型 $`B\to I`$ が存在することをいう。

これは函手 $`\operatorname{Hom}_R(-,I)`$ が完全であることと同値である。
加群の圏は十分多くの入射対象をもつため、任意の加群は入射解消をもつ。
この解消を用いて右 [導来関手](./derived_functor.md) を計算する。

体上のベクトル空間は入射加群である。
可除アーベル群は $`\mathbb{Z}`$-加群として入射である。
