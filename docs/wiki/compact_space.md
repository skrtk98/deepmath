# コンパクト空間

## 定義

> [!definition] コンパクト空間
> 位相空間 $`X`$ が **コンパクト** であるとは、$`X`$ の任意の開被覆が有限部分被覆を持つことである。

部分集合 $`K\subseteq X`$ が部分空間としてコンパクトであるとき、$`K`$ をコンパクト集合という。

## 性質

連続写像 $`f\colon X\to Y`$ とコンパクト部分集合 $`K\subseteq X`$ に対して、$`f(K)`$ は $`Y`$ のコンパクト部分集合である。

有限位相空間はコンパクトである。

実数直線の閉区間 $`[a,b]`$ は通常の位相についてコンパクトである。
