# 代数拡大

## 定義

> [!definition] 代数拡大
> 体の拡大 $`L/K`$ が **代数拡大** (*algebraic extension*) であるとは、$`L`$ のすべての元が $`K`$ 上代数的であることである。
> 代数拡大でない体の拡大を**超越拡大** (*transcendental extension*) という。

## 例

拡大 $`\mathbb{Q}(\sqrt{2})/\mathbb{Q}`$ は代数拡大である。

一方、有理関数体 $`K(T)`$ の拡大 $`K(T)/K`$ では、元 $`T`$ は $`K`$ 上超越的であるため、この拡大は代数拡大ではない。

## 性質

有限次拡大は代数拡大である。

また、$`\alpha`$ が $`K`$ 上代数的であることと、単拡大 $`K(\alpha)/K`$ が有限次拡大であることは同値である。
