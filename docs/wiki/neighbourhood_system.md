# 近傍系

## 定義

位相空間 $`X`$ と点 $`x\in X`$ を考える。

> [!definition] 近傍
> 部分集合 $`N\subseteq X`$ が点 $`x`$ の **近傍** (*neighborhood*) であるとは、$`x\in U\subseteq N`$ を満たす開集合 $`U`$ が存在することである。

点 $`x`$ の近傍全体の集合を $`\mathcal{N}_X(x)`$ と表し、$`x`$ の**近傍系**という。

## 性質

近傍系 $`\mathcal{N}_X(x)`$ は、$`x`$ を含む集合族である。

近傍 $`N`$ を含む部分集合も $`x`$ の近傍である。

二つの近傍の共通部分は $`x`$ の近傍である。

開集合 $`U`$ が点 $`x`$ を含むとき、$`U`$ は $`x`$ の近傍である。

## 連続性との関係

位相空間の間の写像 $`f\colon X\to Y`$ が点 $`x\in X`$ で連続であることは、任意の $`f(x)`$ の近傍 $`V`$ に対して、$`f^{-1}(V)`$ が $`x`$ の近傍であることと同値である。
