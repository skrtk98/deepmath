# 双線形写像

## 定義

> [!definition] 双線形写像
> 可換環 $`R`$ 上の加群 $`M,N,P`$ に対して、写像 $`B\colon M\times N\to P`$ が **双線形写像** (*bilinear map*) であるとは、任意の $`x\in M`$ に対して $`y\mapsto B(x,y)`$ が $`R`$-線形写像であり、任意の $`y\in N`$ に対して $`x\mapsto B(x,y)`$ が $`R`$-線形写像であることである。

すなわち、各変数を他方を固定して動かしたとき、$`B`$ は線形である。

## 例

可換環 $`R`$ 自身に対する乗法
```math
R\times R\longrightarrow R,\qquad (a,b)\longmapsto ab
```
は双線形写像である。

ベクトル空間 $`V`$ 上の内積は、実数体上の双線形写像の例である。

双線形写像は、テンソル積の普遍性を通じて線形写像として扱うことができる。
